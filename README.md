# field-audit-checklist-rn

A lightweight **React Native (Expo)** checklist application for field and bench inspections, featuring status cycling (`PASS`, `FLAGGED`, `FAIL`, `PENDING`), per-item inspection notes, status filtering, custom item entry, and a live JSON export payload.

## Quickstart

```bash
git clone [https://github.com/B5IVE/field-audit-checklist-rn.git](https://github.com/B5IVE/field-audit-checklist-rn.git)
cd field-audit-checklist-rn

npm install
npx expo start
